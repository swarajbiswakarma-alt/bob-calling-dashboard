# BOB Calling Client Dashboard
A deployable light-theme dashboard for the BOB Calling Google Sheet.

Features: live Google Sheet refresh, date/disposition/sub-disposition filters, KPI cards, disposition and sub-disposition charts, daily trend, callback queue, summary, detailed records and CSV export.

Deploy the folder to Vercel. The `/api/sheet` function reads the shared Google Sheet; `/public/data.json` is the current Excel-derived fallback.
